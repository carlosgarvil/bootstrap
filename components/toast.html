Toasts con autohide y apilados

Cada toast desaparecerá automáticamente a los 5 segundos y se apilará con los demás.

Cómo funcionan los toasts

1️⃣ Crear la plantilla HTML del toast desde JavaScript

Cada vez que pulsas el botón, se crea un nuevo toast dinámicamente y se añade al contenedor. Bootstrap permite activar autohide con un tiempo personalizado. 

const toastHtml = `
<div class="toast align-items-center text-bg-primary border-0" role="alert"
     aria-live="assertive" aria-atomic="true"
     data-bs-autohide="true" data-bs-delay="5000">

  <div class="d-flex">
    <div class="toast-body">
      Hola! Este toast desaparecerá en 5 segundos.
    </div>

    <button type="button" class="btn-close btn-close-white me-2 m-auto"
            data-bs-dismiss="toast"></button>
  </div>
</div>`;

2️⃣ Convertirlo en un objeto Toast de Bootstrap

// Convertimos el HTML en un nodo real
const wrapper = document.createElement("div");
wrapper.innerHTML = toastHtml;

const toastElement = wrapper.firstElementChild;

// Insertamos el toast en el contenedor
document.getElementById("toastContainer").appendChild(toastElement);

// Instanciamos el toast de Bootstrap
const toast = new bootstrap.Toast(toastElement);

// Mostrar el toast
toast.show();

Bootstrap se encarga de:

  • mostrar el toast,
  • ocultarlo automáticamente a los 5s,
  • y apilarlo si hay más toasts activos.
