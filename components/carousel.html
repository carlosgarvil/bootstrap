Cómo controlar el carrusel

1️⃣ Control mediante atributos data-bs-*

Bootstrap permite controlar el carrusel sin escribir JavaScript. Los atributos más importantes son:

  • data-bs-ride="carousel" → activa el autoplay.
  • data-bs-target="#carouselEjemplo" → indica qué carrusel controlar.
  • data-bs-slide="next" → mueve a la siguiente diapositiva.
  • data-bs-slide="prev" → mueve a la anterior.
  • data-bs-slide-to="1" → salta al slide número 1.
<button data-bs-target="#carouselEjemplo" data-bs-slide="next">Siguiente</button>
<button data-bs-target="#carouselEjemplo" data-bs-slide-to="2">Ir al slide 3</button>

2️⃣ Control mediante JavaScript

Con JS tienes control total del carrusel:

const el = document.getElementById("carouselEjemplo");
const carousel = new bootstrap.Carousel(el);
Métodos disponibles:
carousel.next();      // pasa a la siguiente
carousel.prev();      // pasa a la anterior
carousel.to(2);       // va al slide 3 (índice 2)
carousel.pause();     // pausa el autoplay
carousel.cycle();     // reanuda el autoplay

Ejemplo práctico:

<script>
  const el = document.getElementById("carouselEjemplo");
  const carousel = new bootstrap.Carousel(el, {
    interval: 3000,   // tiempo entre slides
    pause: "hover"    // pausa al pasar el ratón
  });

  // Cambiar automáticamente al slide 3 a los 5s
  setTimeout(() => {
    carousel.to(2);
  }, 5000);
</script>
