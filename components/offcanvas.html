Cómo controlar el Offcanvas

1️⃣ Apertura/cierre mediante data-bs-*

La forma más rápida de abrir un Offcanvas es usar un botón con data-bs-toggle="offcanvas" y data-bs-target apuntando al id del menú: 

<button class="btn btn-primary"
        type="button"
        data-bs-toggle="offcanvas"
        data-bs-target="#menuLateral"
        aria-controls="menuLateral">
  Abrir menú lateral
</button>

Y el propio offcanvas se define con la clase .offcanvas offcanvas-start para que aparezca desde la izquierda: 

<div class="offcanvas offcanvas-start" id="menuLateral">
  ...
</div>

El botón de cierre dentro del menú usa data-bs-dismiss="offcanvas", así Bootstrap se encarga de cerrarlo automáticamente: 

<button type="button" class="btn-close" data-bs-dismiss="offcanvas"></button>

2️⃣ Control mediante JavaScript

Si quieres controlar el menú desde JavaScript (abrir, cerrar, saber cuándo se oculta, etc.), necesitas crear una instancia de bootstrap.Offcanvas: 

const offcanvasEl  = document.getElementById("menuLateral");
const offcanvas    = new bootstrap.Offcanvas(offcanvasEl);

const btnAbrirMenu = document.getElementById("btnAbrirMenu");

btnAbrirMenu.addEventListener("click", () => {
  offcanvas.show();  // abre el menú
});

Métodos útiles

offcanvas.show();   // abre el menú
offcanvas.hide();   // cierra el menú
offcanvas.toggle(); // alterna abrir/cerrar

3️⃣ Detectar qué opción del menú se ha pulsado

Cada enlace del menú tiene un atributo data-opcion con el nombre de la opción. Desde JS escuchamos el click y actualizamos el texto de la página (y podríamos ejecutar más lógica si hiciera falta): 

const textoOpcion = document.getElementById("opcionSeleccionada");
const itemsMenu   = document.querySelectorAll(".menu-item");

itemsMenu.forEach(item => {
  item.addEventListener("click", (event) => {
    const opcion = event.currentTarget.dataset.opcion;
    textoOpcion.textContent = opcion;

    // Cerrar el menú después de hacer clic
    offcanvas.hide();

    console.log("Has pulsado la opción:", opcion);
    // Aquí podrías llamar a funciones, cargar contenido, etc.
  });
});

4️⃣ Eventos del Offcanvas (opcional)

Bootstrap dispara eventos cuando el menú se muestra u oculta, por ejemplo shown.bs.offcanvas y hidden.bs.offcanvas: 

offcanvasEl.addEventListener("shown.bs.offcanvas", () => {
  console.log("El menú lateral se ha abierto");
});

offcanvasEl.addEventListener("hidden.bs.offcanvas", () => {
  console.log("El menú lateral se ha cerrado");
});
