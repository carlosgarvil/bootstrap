Cómo controlar qué pasa al pulsar Aceptar o Cancelar

La idea básica es:

  1. Obtener referencias a los botones Aceptar y Cancelar.
  2. Escuchar el evento click en cada uno.
  3. Dentro de cada click, ejecutar las acciones que quieras.

1️⃣ Referencias a los elementos del DOM

const modalEl     = document.getElementById("ejemploModal");
const modal       = new bootstrap.Modal(modalEl);
const btnAbrir    = document.getElementById("btnAbrirModal");
const btnAceptar  = document.getElementById("btnAceptar");
const btnCancelar = document.getElementById("btnCancelar");
const resultadoEl = document.getElementById("resultado");

2️⃣ Abrir el modal con JavaScript

btnAbrir.addEventListener("click", () => {
  modal.show();
});

3️⃣ Acciones diferentes para Aceptar / Cancelar

Como los botones tienen data-bs-dismiss="modal", Bootstrap se encarga de cerrar el modal automáticamente. Nosotros solo nos ocupamos de la lógica de cada botón: 

btnAceptar.addEventListener("click", () => {
  // Aquí iría la lógica de "Aceptar"
  resultadoEl.textContent = "Has pulsado Aceptar ✅";
  console.log("Acción aceptada");
});

btnCancelar.addEventListener("click", () => {
  // Aquí iría la lógica de "Cancelar"
  resultadoEl.textContent = "Has pulsado Cancelar ❌";
  console.log("Acción cancelada");
});

Aquí podrías sustituir el console.log por:

  • Enviar datos a un backend.
  • Redirigir de página.
  • Actualizar la interfaz (por ejemplo, eliminar un registro de una tabla).

4️⃣ (Opcional) Usar el evento del modal

A veces quieres tomar decisiones cuando el modal ya se ha cerrado. Puedes usar los eventos de Bootstrap, por ejemplo hidden.bs.modal. 

let ultimaAccion = null;

btnAceptar.addEventListener("click", () => {
  ultimaAccion = "aceptar";
});

btnCancelar.addEventListener("click", () => {
  ultimaAccion = "cancelar";
});

modalEl.addEventListener("hidden.bs.modal", () => {
  if (ultimaAccion === "aceptar") {
    console.log("Ejecutar lógica final de ACEPTAR");
  } else if (ultimaAccion === "cancelar") {
    console.log("Ejecutar lógica final de CANCELAR");
  }
});

Este patrón es útil si necesitas estar seguro de que el modal se ha cerrado antes de continuar.
